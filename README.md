<h1>Favorite Teams Interface Using JavaFX and MySQL</h1>
<h2>Description</h2>
<p>Project consists of a JavaFX interface that connects to a MySQL database to display and allow the user to update information.</p>
<p>By using JDBC, the application connects to a MySQL database to retrieve and store information. Queries with wildcards are written to be replaced with user input through the application interface. The interface is created using JavaFX, and fields are filled using information returned from the SQL query upon user interaction with the "display" button. Once the fields are filled, the user has the option to edit either the first name, last name, or favorite team. Upon clicking the "update" button, the database will be updated with the new information that the user provided.</p>
